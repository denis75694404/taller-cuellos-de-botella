# Taller: cuellos de botella

Taller participativo en vivo por grupos de hasta 5 integrantes.

- `admin.html` — panel del facilitador (pide código de administrador): crea la sala, define la pregunta, controla el tiempo y las etapas, y ve todos los grupos.
- `grupos.html` — página para los participantes: entran con el código o QR, eligen su grupo, responden, votan (1 voto) y ven solo los resultados de su grupo.
- `firebase-config.js` — conexión con Firebase (la usan las dos páginas).
- `firestore.rules` — reglas de seguridad de Firestore.
- `pantalla-unica.html` — versión sin internet para una sola laptop.
