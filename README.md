# Taller: cuellos de botella

Página para facilitar un taller participativo en una sola pantalla (laptop + proyector).

1. **Responder**: las respuestas se escriben como en un chat o se pegan desde WhatsApp.
2. **Votar**: por turnos (cada persona marca 2 propuestas distintas) o contando post-it con + / −.
3. **Resultados**: podio con las 3 prioridades, ranking completo, exportación a CSV, copia e impresión/PDF.

Todo se guarda en el navegador de la laptop que la abre (sin servidor ni cuentas).

**Uso:** abre `index.html` en Chrome o Edge, o entra a la versión publicada en GitHub Pages.
